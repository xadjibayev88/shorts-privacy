Shorts Agent

Shorts Agent is a personal automation tool. It creates short videos and uploads them to the owner's own YouTube channel using the YouTube Data API.

Privacy Policy

The app is used only by its owner. It requests the youtube.upload permission solely to upload videos to the owner's channel.

The app does not collect, store, sell or share any personal data of other users. OAuth tokens are stored only as encrypted secrets in the owner's private GitHub repository.

Access can be revoked at any time at myaccount.google.com/permissions.

Terms of Service

The app is provided as is, for the owner's personal use only.
